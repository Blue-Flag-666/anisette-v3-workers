# anisette-v3-workers

A Cloudflare Workers port of `anisette-v3-server`, providing its Anisette v1 and v3 server protocols.

It also provides `/servers.json`, which extends the official SideStore server list with the current deployment URL.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/Blue-Flag-666/anisette-v3-workers)
